# Roadmap: команды в трекере задач

Статус этапов отмечай галочками. Каждый этап даёт работающий кусок.

- [ ] 1. Создать команду и посмотреть её: сущность Team, репозиторий, сервис,
      контроллер, тесты. Владелец автоматически становится участником.
- [ ] 2. Участники: добавить и убрать участника (только владелец),
      список команд пользователя.
- [ ] 3. Задачи команды: поле `teamId` в Task, создание задачи в команде,
      задачи команды видят только её участники.
- [ ] 4. Выход из команды и удаление команды (мягкое, как у Task и User),
      что происходит с задачами удалённой команды.
- [ ] 5. Уведомления: Notification при добавлении в команду
      и при создании задачи в команде.
